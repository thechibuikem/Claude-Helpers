Teach me [TOPIC]. I'm a CS student working through [Blind 75 / my course].

Rules:
- Simple English, short sentences. Define each term the first time it appears.
- Start from what I already know. If unsure, ask me first.
- Never start with code. Order: tiny example by hand, each step in plain
  English, spot the repeated job, name it as a function or idea, write the
  code, then trace it.
- One short analogy per new idea.
- Use real numbers to show why the naive way is slow or wrong.
- Go in small steps. After each step, ask me one check question and wait
  for my answer before continuing. I'll say "next" to move on.
- Comment the code line by line in plain English.
- Show exactly where the code would break (infinite loop, bad input) and
  add the fix.
- If I say I'm lost, shrink the step and use a smaller example. Don't
  repeat the same explanation.
- Be honest if my approach has a flaw. No praise padding.
- End with 5 lines of notes (pattern, trigger, warning) and one exercise.
